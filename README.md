# Monolith

Телефонное приложение называется **Monolith** (Bundle ID `com.monolith.app`). Это личный учёт одного человека, который льёт белый арбитраж трафика. Семь экранов на iPhone и сервер с данными. Веб-интерфейса нет: телефон и бот ходят в API разными ключами. На главном экране внутри приложения заголовок по-прежнему «Дисциплина» — так на макете. Под иконкой на домашнем экране iPhone написано Monolith. Иконка — куб на воде без надписи. Экран запуска — туманный берег с надписью MONOLITH, картинка заполняет экран, под ней тёмный цвет воды.

Пример в базе — день **14 ноября 2026**, капитал **$1 000**. Цифры на экранах те же, что на макетах: баланс $789.40, прибыль за день +$34.20, пять связок, четыре живых гео и одно в стопе.

## Что внутри

- `ios/Monolith.xcodeproj` — приложение SwiftUI, iOS 17+, только iPhone. Русский интерфейс, шрифт Manrope, карточки «jelly», переключаемая монохромная тема. Сборку без подписи делает GitHub Actions, файл `.ipa` ставится через AltStore.
- `server/` — API на Python (FastAPI, SQLite). OpenAPI: `/docs`.

На телефоне есть замок (код и Face ID или Touch ID), локальный кэш и очередь правок, которая уходит на сервер, когда сеть возвращается, и локальные уведомления по срабатыванию правил.

## Сервер на Windows

Нужен Python 3.11 или новее и PowerShell. Порт API — **8741**. Слушать его нужно только на localhost, наружу его открывает Tailscale, не проброс на роутере.

### 1. Поставить Python

Скачайте установщик с [python.org](https://www.python.org/downloads/windows/) и на первом экране включите **Add python.exe to PATH**. В новом окне PowerShell:

```powershell
python --version
```

Должно быть 3.11 или выше.

### 2. Поставить зависимости и ключи

Откройте PowerShell **от имени администратора**, перейдите в папку `server` этого репозитория и выполните:

```powershell
cd server
powershell -ExecutionPolicy Bypass -File .\install\install-service.ps1
```

Скрипт делает следующее:

1. Создаёт виртуальное окружение `.venv`.
2. Ставит зависимости из `requirements.txt`.
3. Если файла `.env` ещё нет, записывает два случайных ключа: `DISCIPLINA_IOS_API_KEY` для телефона и `DISCIPLINA_BOT_API_KEY` для бота.
4. Заполняет базу примером (`python -m app.seed`).
5. Регистрирует задание планировщика **DisciplinaServer**. Оно стартует вместе с Windows от SYSTEM и поднимает процесс заново, если тот упал.

Ключи лежат в `server/.env`. Файл не коммитьте. Ключ телефона потом вставляется в меню «•••» на айфоне. Ключ бота — в того ассистента, который читает статистику и пишет сводки.

Проверка с этого же компьютера:

```powershell
curl http://127.0.0.1:8741/health
```

Ответ: `{"ok":true,"name":"Дисциплина"}`. Описание API: [http://127.0.0.1:8741/docs](http://127.0.0.1:8741/docs).

Остановить службу:

```powershell
powershell -ExecutionPolicy Bypass -File .\install\uninstall-service.ps1
```

База при этом не удаляется. Посмотреть лог в консоли, без службы:

```powershell
powershell -ExecutionPolicy Bypass -File .\install\start-console.ps1
```

Повторить пример с нуля (сотрёт ваши проводки):

```powershell
.\.venv\Scripts\python.exe -m app.seed
```

### 3. Docker, если он удобнее службы

Из папки `server`, после того как `.env` уже создан:

```powershell
copy .env.example .env
docker compose up -d --build
```

Контейнер публикует порт только на `127.0.0.1:8741`. В `.env` всё равно задайте свои ключи, не оставляйте `dev-ios-key` и `dev-bot-key`.

### 4. Tailscale

Сервер не должен торчать в интернет. Телефон и бот попадают к нему через вашу tailnet.

1. Поставьте [Tailscale](https://tailscale.com/download/windows) на Windows-сервер и на iPhone. Войдите в один аккаунт.
2. В админке Tailscale включите MagicDNS.
3. На сервере API уже слушает `127.0.0.1:8741`. Включите HTTPS-прокси Tailscale:

```powershell
tailscale serve --bg --https=443 http://127.0.0.1:8741
tailscale serve status
```

4. Имя машины будет вида `https://имя-компьютера.ваша-tailnet.ts.net`. Его и вставляйте в телефон как адрес сервера.
5. Не открывайте порт 8741 в брандмауэре для сети «Public» и не делайте проброс на роутере. Ключ в заголовке `X-API-Key` остаётся вторым замком на случай, если кто-то окажется в той же tailnet.

Если `tailscale serve` не хотите, можно ходить по HTTP на адрес `100.x.y.z:8741`. Для этого в `.env` поставьте `DISCIPLINA_HOST` равным этому адресу и перезапустите задание. В приложении тогда адрес `http://100.x.y.z:8741`. Для личного приложения, которое не идёт в App Store, HTTP внутри tailnet разрешён (ATS ослаблен в Info.plist). HTTPS через `tailscale serve` всё равно лучше.

## Ключи и что кому можно

Заголовок каждого запроса, кроме `/health`: `X-API-Key`.

| Ключ | Читать | Дневная статистика, проводки, ставки гео | Журнал | Правила, задачи, связки |
| --- | --- | --- | --- | --- |
| Телефон | да | да | да | да |
| Бот | да | да | да | нет |

Полезные пути:

- `GET /api/v1/snapshot` — весь экранный снимок одним ответом.
- `GET /api/v1/rules/check` — сверка цифр с правилами. В ответе отдельные списки `violations`, `warnings` и `signals`.
- `POST /api/v1/journal` — сводка бота.
- `POST /api/v1/bundles/{id}/stats` — расход, доход, клики и конверсии за день. Итоги связки пересчитываются из дней.
- `POST /api/v1/sync` — пачка правок, которые телефон накопил без сети.

На примере нарушений нет: Мексика уже в стопе, дневной расход $38 из $50 — это предупреждение, а Польша даёт сигнал масштабирования (ROI выше 50% дольше семи дней).

## Установка Monolith через AltStore

Mac и платный аккаунт Apple Developer не нужны. Бесплатный Apple ID подписывает приложение на 7 дней. Лимит бесплатного Apple ID — несколько приложений и до десяти App ID; одно приложение Monolith в него укладывается. В проекте нет push, App Groups, iCloud и Associated Domains: бесплатный Apple ID такие возможности не подписывает. Face ID и локальные уведомления остаются, для них отдельная capability не нужна.

Сборку делает GitHub Actions (файл `.github/workflows/ios-ipa.yml`): macOS-раннер, `xcodebuild archive` для generic iOS device с `CODE_SIGNING_ALLOWED=NO`, затем архив упаковывается в неподписанный `Monolith.ipa` и кладётся в артефакт. AltStore подписывает его уже вашим Apple ID.

### 1. AltServer на Windows

Ставьте программы Apple с сайта Apple, не из Microsoft Store. Версии из Store не отдают AltServer доступ к телефону.

1. Скачайте iTunes: [https://www.apple.com/itunes/download/win64](https://www.apple.com/itunes/download/win64) (если система 32-битная, на той же странице есть win32). Установщик `.exe` с apple.com, не приложение «iTunes» из Store.
2. Скачайте iCloud для Windows с [https://support.apple.com/en-us/103227](https://support.apple.com/en-us/103227) — тоже установщик с apple.com, не «iCloud» из Store. Если iCloud уже стоит из Store, удалите его и поставьте заново с сайта.
3. Скачайте AltServer для Windows с [https://altstore.io](https://altstore.io) и установите. В трее появится значок AltServer.
4. Подключите iPhone кабелем, на телефоне нажмите «Доверять». В iTunes или в приложении «Apple Devices» телефон должен быть виден.
5. В меню AltServer выберите **Install AltStore** и этот iPhone. Введите Apple ID и пароль того аккаунта, которым пользуетесь на телефоне. Если включена двухфакторная защита, придёт код.
6. На iPhone: Настройки → Основные → VPN и управление устройством → доверьтесь своему Apple ID.

### 2. Режим разработчика

На iOS 16 и новее боковая установка без этого не запускается.

1. Настройки → Конфиденциальность и безопасность → **Режим разработчика**.
2. Включите, телефон перезагрузится, подтвердите включение.

### 3. Скачать Monolith.ipa и поставить

1. Откройте GitHub → Actions → workflow **iOS IPA** → удачный запуск → артефакт **Monolith-ipa** → скачайте `Monolith.ipa`.
2. Перенесите файл на iPhone (AirDrop не с Windows; подойдут iCloud Drive, ссылка в браузере телефона или «Файлы»).
3. Откройте AltStore → **My Apps** → **+** → выберите `Monolith.ipa`.
4. Дождитесь установки. Первые 7 дней приложение запускается. Потом подпись протухает, пока AltStore её не обновит.

Первый запуск Monolith просит код из 4 цифр и предлагает Face ID (на старом телефоне — Touch ID). Пока адрес сервера пустой, на экране пример. В «•••» вставьте адрес Tailscale и ключ телефона из `server/.env`. Монохром включается там же. «Проверить уведомление» — локальный баннер, не push.

### 4. Продление каждые 7 дней

AltStore сам переподписывает приложения, если выполнены три условия:

- iPhone и компьютер с AltServer в одной сети Wi-Fi;
- компьютер включён, AltServer запущен (значок в трее), телефон не в режиме сна насовсем;
- у AltStore включено обновление контента: Настройки iPhone → Основные → Обновление контента → AltStore.

Телефон периодически будит AltStore, тот стучится к AltServer, и подпись обновляется до истечения 7 дней. Если компьютер был выключен всю неделю, откройте AltStore при включённом ПК в той же Wi-Fi и обновите Monolith вручную: My Apps → Monolith → Refresh. Кабель для продления не нужен, он нужен был для первой установки AltStore.

## Проверки

Тесты сервера, из папки `server`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
```

На Linux и macOS то же самое с `bin/python` вместо `Scripts\python.exe`.

## Что проверено, а что нет

Проверено здесь: `pytest` (снимок примера совпадает с текстами макетов, права двух ключей, синхронизация, нарушение стоп-лосса связки), живой процесс API и OpenAPI на `/docs`.

Не проверено: прогон GitHub Actions и `xcodebuild` — на этой машине нет macOS, поэтому неподписанный IPA ещё ни разу не собирался. Не ставилась служба Windows, не поднимался Tailscale и AltStore, Face ID на устройстве не нажимался. Цвета, радиусы, тени и блик карточек в `ios/Monolith/Design/Theme.swift` совпадают с `jelly.css`, `common.css` и HTML экранов.
